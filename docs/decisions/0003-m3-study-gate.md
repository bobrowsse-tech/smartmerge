# Milestone 3 study gate

- **Status:** Accepted
- **Date:** 2026-09-29
- **Context:** The milestone 3 acceptance line says the usability gates in the visual spec are met, and it names the System Usability Scale. That same section is titled as a gate before version 1.0. The evaluation spec schedules the user study as pre-v1, and milestone 9 owns that study. A score cannot be measured without participants.
- **Decision:** Do not record a usability score or a novice success rate. Milestone 3 stays open until those two results come from a real study. The dashboard, accessibility checks, layout checks, speed budgets for the features that exist, and the editor pre-release are in scope now. Type and lint checks stay in milestone 5. Until those checks exist, the verification strip shows them as not run and must not show them as passed. Milestone 4 does not start while milestone 3 is open.
- **Consequences:** A later study can close the two human gates. Closing them by writing a number into the roadmap is a false measurement and is rejected.
