# Governance

SmartMergeResolver is maintained by [Bob Rowsse Walakira](https://bobrowsse.com). Contact: [hello@bobrowsse.com](mailto:hello@bobrowsse.com). The GitHub account for this repository is bobrowsse-tech.

## What is public

Anyone can read the code, clone it, and fork it. Issues are open. Discussions can be used for questions that are not bug reports.

## What maintainers do

Maintainers are the only people who open pull requests that will be merged, review them, and merge them. Merging happens on GitHub after the required checks pass. `main` is protected from deletion and from direct pushes, including for admins.

## Conduct

See `CODE_OF_CONDUCT.md`.

## Security reports

See `SECURITY.md`. Do not file public issues for vulnerabilities.

## Changes to this model

Widening pull-request access, choosing a license, or renaming the project is a maintainer decision recorded in `docs/decisions/`.
