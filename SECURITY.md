# Security

## Reporting

Report a vulnerability through a [private security advisory](https://github.com/bobrowsse-tech/smartmerge/security/advisories/new) on this repository. Do not open a public issue for a security report.

## Response

Maintainers aim to acknowledge a report within 3 days and to send a fuller assessment within 14 days. Those are targets for this early stage, not a contractual SLA.

## Scope

In scope: the daemon, CLI, protocol, and editor adapters in this repository, once they exist. The repository is in design phase. Specs are not a running product yet.

Out of scope: vulnerabilities in dependencies that do not affect this repository, and social-engineering of maintainers.
